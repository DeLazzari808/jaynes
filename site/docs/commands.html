Commands

Your agent runs most of these; you need few of them. jaynes alone opens the page, starting it if it is not running. Every command also takes --help, and those that keep state take --home, the folder Jaynes keeps it in: JAYNES_HOME, or ~/.jaynes.

The page

jaynes review

Serve the page, in the foreground.

jaynes review [-h] [--port PORT] [--home HOME] [--open]
--port
the page's port default 8740
--open
open the page in the browser, unless it already runs

jaynes demo

Start the demo: a scripted agent works through a role and stops for you, with no API key or quota.

jaynes demo [-h] [--port PORT] [--home HOME] [--no-serve]
--port
the page's port default 8740
--no-serve
start the run and exit, without the review page

jaynes update

Install the newest Jaynes, if there is one.

jaynes update [-h] [--home HOME]

jaynes version

The commit of Jaynes installed, and where it came from.

jaynes version [-h]

Runs

jaynes run

Start a run of a role on a task, or continue one by its id.

jaynes run [-h] [--role ROLE] [--task TASK] [--runtime RUNTIME] [--project PROJECT] [--preview PREVIEW] [--preview-path PREVIEW_PATH] [--preview-ports PREVIEW_PORTS] [--suite SUITE] [--input INPUT] [--here] [--home HOME] [id]
id
a run to continue
--role
a role by its name, as jaynes roles lists the roles of the project's packages; a role file (.toml), a Python file's path.py:attribute, or module:attribute
--task
what the run is asked to do, in full
--runtime
name=module:attribute, overrides a runtime
--project
a folder in a git repository, for steps that work on a project
--preview
a command that serves the project on {port}, shown at stops
--preview-path
the path to open in the preview, / by default
--preview-ports
local ports the preview may connect to, such as a backend: 8789,5432
--suite
the command that runs the project's whole test suite, when Jaynes does not find it (fix-bug, build-feature, small-change)
--input
name=value, an input the role declares, such as --input method=method.md
--here
started from an agent's terminal: its stops are asked there, and the page opens only when asked

jaynes plan

A request that needs more than one role: its runs, each starting once the runs it follows delivered.

jaynes plan [-h] [--project PROJECT] [--home HOME] plan
plan
the plan as JSON in a file, or - for stdin: {"request": "<the person's words>", "runs": [{"name": "identity", "role": "visual-identity", "task": "...", "after": []}, ...]}; a run may also give preview, preview_path, preview_ports, suite and inputs, as jaynes run takes them
--project
the folder in a git repository every run works on

jaynes queue

What waits for an answer, with the evidence hash each stop showed.

jaynes queue [-h] [--home HOME]

jaynes answer

Answer a run's open stop as an agent, and continue the run.

jaynes answer [-h] [--chosen CHOSEN] [--note NOTE] [--output OUTPUT] [--to TO] [--evidence EVIDENCE] [--home HOME] run step {accept,change,return,context,choose}
run
the run's id
step
the step whose stop is open
accept | change | return | context | choose
--chosen
with choose: the ids kept, in order of importance, such as M3,M1
--note
what to change or why, in a sentence; with return and context it goes to the agent
--output
the edited output for change: JSON, or @file
--to
with return or context: an earlier step to run again, with every step after it
--evidence
the evidence hash jaynes queue printed; refuses the answer if the stop changed

jaynes ask

The open stop of a run, as input for Claude Code's question dialog.

jaynes ask [-h] [--home HOME] run
run
the run's id

jaynes wait

Wait until the person answers a run's stop on the page, then go on with the run.

jaynes wait [-h] [--home HOME] [--every EVERY] run
run
the run's id, or a plan's request
--every
seconds between looks default 2.0

jaynes output

The checked output of a step of a run, as JSON.

jaynes output [-h] [--home HOME] run step
run
the run's id
step
the step's name

jaynes delivered

Runs that delivered, newest first, with their steps, files and corrections.

jaynes delivered [-h] [--project PROJECT] [--limit LIMIT] [--home HOME]
--project
only runs on the git repository that holds this folder
--limit
how many runs to list default 10

jaynes correct

Record that a delivery was corrected afterwards, and why.

jaynes correct [-h] --step STEP --kind {error,preference,info} --note NOTE [--home HOME] run
run
the run that delivered what is being corrected
--step
the step whose output was wrong
--kind
error: wrong by what was already known; preference: a new one nobody had written; info: the world changed or a new fact appeared. Only an error counts
--note
what was wrong, in a sentence

jaynes halt

Halt every run before its next step, and every merge, until the person resumes on the page.

jaynes halt [-h] [--note NOTE] [--home HOME]
--note
why, in a sentence

Roles and packages

jaynes roles

The roles a run on a project can start by name, from the packages it uses.

jaynes roles [-h] [--project PROJECT] [--home HOME]
--project
the project; the folder you are in when it is in a git repository

jaynes check

Find what a role gets wrong before any agent runs.

jaynes check [-h] [--home HOME] [--project PROJECT] role
role
a role by its name, as jaynes roles lists them, a role file (.toml), a Python file's path.py:attribute, or module:attribute
--project
the project whose packages name the role; the default list otherwise

jaynes add

Install a package of roles, or link a folder of yours, for one project or for every project.

jaynes add [-h] [--project PROJECT] [--ref REF] [--folder FOLDER] [--home HOME] source
source
a package that comes with Jaynes (software, design), a folder with jaynes-package.toml, linked where it is, or a git repository
--project
only this project; without it, every project with no list of its own
--ref
a git branch, tag or commit; a commit stays as it is on jaynes update
--folder
the folder in the repository that holds the package, if not its top

jaynes remove

Stop using a package in a project, or in the default list.

jaynes remove [-h] [--project PROJECT] [--home HOME] name
name
the package's name, as jaynes packages lists it
--project
only this project; without it, the default list

jaynes packages

The packages installed, and which projects use which.

jaynes packages [-h] [--home HOME]

Your agents' history and the action gate

jaynes history

How many of your agents' tool calls a person approved, read from Claude Code's transcripts; it changes nothing.

jaynes history [-h] [--config CONFIG] [--days DAYS] [--cwd CWD] [--top TOP]
--config
the policy that classifies the calls; the built-in one otherwise
--days
how far back to read default 30
--cwd
only sessions in this folder
--top
how many unclassified commands to list default 25

jaynes simulate

How often a stop that should keep asking would be wrongly sampled, with Jaynes's test and with the usual shortcut.

jaynes simulate [-h] [--budget BUDGET] [--delta DELTA] [--runs RUNS] [--horizon HORIZON] [--seed SEED] [--p P [P ...]]
--budget
the share of changed answers a stop tolerates default 0.05
--delta
the chance of being wrong the guarantee allows default 0.05
--runs
simulated stops per true change rate default 4000
--horizon
answers per simulated stop default 2000
--seed
the random seed, so a result can be repeated default 1
--p
the true change rates to simulate default [0.0, 0.01, 0.02, 0.03, 0.05, 0.06, 0.08]

jaynes autonomy

What the action gate decided, by category: calls, how many asked you, and how far each is from asking less.

jaynes autonomy [-h] [--config CONFIG] [--db DB]
--config
the policy file; the one the gate uses otherwise
--db
the gate's log; the home's otherwise

jaynes policy

Print the action gate's built-in policy.

jaynes policy [-h]

jaynes parity

Compare a hook of yours with the gate's floors on your past shell commands.

jaynes parity [-h] [--config CONFIG] [--days DAYS] [--top TOP] hook
hook
the hook's command; it blocks a call by exiting with 2
--config
the policy; the built-in one otherwise
--days
how far back to read default 50
--top
how many differing commands to list default 10

How an agent carries out a change through Jaynes; the skill runs it.

jaynes guide [-h]

The MCP server for agents, over stdio: what waits, and the answers an agent may give; Claude Code starts it with the plugin.

jaynes mcp [-h] [--home HOME]

jaynes answered

Claude Code's hook after its question dialog.

jaynes answered [-h]

jaynes hook

The action gate's hook, which Claude Code runs on each tool call once Setup installed it.

jaynes hook [-h]
